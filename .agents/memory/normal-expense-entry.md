---
name: Normal expense entry
description: Defines the durable split between everyday Normal expense logging and the complete Advanced form.
---

New expense forms should default to **Normal**: date, amount, description, and one category. The date defaults to today but remains editable for managers; Jamvi allocates the full amount to that category and uses the signed-in person’s main saved income source (or first saved source). Show these assumptions in plain language.

Keep **Advanced** as the complete path for another date, notes, recurring setup, bank or mixed funding, multiple payers or income sources, and multiple category allocations. Existing-expense edits open in Advanced so saved details are never hidden.

**Why:** Everyday expense logging should be quick without weakening the explicit funding and category rules needed for complex records.

**How to apply:** Keep Normal and Advanced consistent across Dashboard Quick Log, the web Expenses page, and mobile Add Expense. Switching modes must preserve date, amount, description, and category; shared-budget members may record only today’s date. Never silently create an income source when Normal lacks one.
