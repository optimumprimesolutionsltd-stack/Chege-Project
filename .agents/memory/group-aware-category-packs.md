---
name: Group-aware category packs
description: Non-destructive rules for adapting expense categories to a Shared budget's group type.
---

Shared budgets use their declared group type to choose an expense-only starter pack. Contributions, deposits, and member payments remain in their own ledgers rather than appearing as spending categories.

Priority-tier headings must also match the declared group type. Household wording is not an acceptable fallback for a recognized Chama, club, or team. Managers can customize tier names, explanations, and order per workspace; moving a tier moves its assigned categories with it.

Changing a Shared budget's group type must never delete, rename, reset, or overwrite existing categories. Recommended categories for the new type are an explicit, additive action that inserts only missing names using case-insensitive matching.

**Why:** Category settings may contain manager-defined budgets, priorities, and recurrence rules, while historical expenses and bank records retain category names. Automatically replacing a pack would damage customized planning and make history confusing.

**How to apply:** Seed the appropriate pack only for a new or truly empty workspace. For an established workspace, preview missing recommendations and require a manager to apply them; preserve every existing category row unchanged. Use group-aware tier defaults until the manager saves workspace-specific tiers.
