# App content forms

Play Console › Policy › App content. Each must be finished before the first release.

| Form | Answer |
|---|---|
| **Privacy policy** | https://jamvi.co.ke/privacy |
| **Ads** | No, the app contains no ads |
| **App access** | All or some functionality is restricted - give a reviewer account (below) |
| **Content rating** | Questionnaire, category *All other app types*: no violence, sexual content, profanity, drugs, gambling; users can interact (Shared groups with people they invite); shares location: no; digital purchases: yes (if Play Billing is used). Expect *Everyone / 3+* |
| **Target audience** | 18 and over (it manages money and takes payment) |
| **News app** | No |
| **Data safety** | [data-safety.md](data-safety.md) |
| **Government app** | No |
| **Financial features** | Yes: *Personal finance - budgeting, expense tracking*. It does not lend, bank, trade, hold funds, move money or offer crypto. Payments in the app are only for its own subscription |
| **Health** | No |
| **Advertising ID** | No. Jamvi has no advertising or analytics SDK; sign-in opens Google in the browser, not Play services |
| **Account deletion** | In the app: Settings › App › Delete account. Web: https://jamvi.co.ke/privacy#delete-account |

## App access: the reviewer account

Jamvi signs in with Google only, so Google's reviewers need a Google account that already has
a Jamvi budget.

1. Make a new Gmail for this alone (e.g. jamvi.review@gmail.com), no 2-step verification - a
   reviewer cannot receive the code.
2. Sign in to Jamvi with it, and add a test budget: a few categories, a test statement read in,
   one business, one Shared group. No real names or numbers.
3. In App access, give: the email, the password, and *"Sign in with Google using this account.
   The M-Pesa screen's statement import needs an M-Pesa statement PDF; a sample is already
   imported, so the review list and reports show real-looking data."*

Keep the subscription on that account active (or the trial long), so a reviewer never meets a
paywall halfway through.
